# JobFlow — Business Onboarding v0.6

## Purpose

Turn a new tenant into a usable JobFlow workspace.

## Flow

1. Business Profile
2. Industry
3. Services
4. Staff
5. Finish

## Business Profile

Collect:
- Business name
- Email
- Phone
- Website
- Address
- City
- State
- Postal code
- Country
- Currency
- Timezone

## Industry

The owner may:
- select a pre-populated industry template
- create a custom industry

Template selection is a starting point, not a permanent restriction.

## Services

For the selected industry, the owner may:
- select template services
- edit service details
- configure pricing
- configure estimated duration
- add custom services

## Staff

The owner may add:
- name
- email
- phone
- role/title

Later setup can add:
- service skills
- availability
- permissions
- schedules

## Completion

The onboarding process should produce a usable tenant workspace. The dashboard is the operational destination after setup.

## Implementation status

v0.6 provides the route and UX foundation. Persistence, authenticated onboarding transactions, template import and production forms are the next implementation layer.
